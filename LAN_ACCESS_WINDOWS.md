# Доступ к ODE из локальной сети — legacy/dev only

> **Не является поддержанным deployment ODE 0.21.1.** Файлы
> `start_lan_windows.bat` и `setup_lan_access_windows.bat` исключены из
> публичного Windows source package. Текущий HTTP runtime не имеет TLS,
> `Secure` cookie, persistent sessions и полноценного server security profile.
> Для рабочей эксплуатации используйте только локальный `127.0.0.1`; этот
> документ сохранён для контролируемой разработки и не является инструкцией
> rollout.

## Первичная настройка

1. Один раз запустите `setup_lan_access_windows.bat` от имени администратора.
2. Только в явно разрешённом dev-контуре запускайте `start_lan_windows.bat`.
3. Окно ODE должно оставаться открытым. Для остановки нажмите `Ctrl+C`.

Launcher выводит доступные адреса вида:

```text
http://192.168.1.6:8765
```

Тестовый клиент открывает подходящий адрес в браузере. Оба компьютера должны
быть в изолированной доверенной dev-сети; наличие VPN само по себе не делает
такой запуск production-безопасным.

Правило брандмауэра разрешает входящие подключения только на TCP-порт `8765`,
только для Python, запускающего ODE, и только из локальных подсетей.

Не настраивайте проброс порта `8765` на интернет-роутере. ODE 0.21.1 работает
по HTTP без TLS; многопользовательский LAN/server deployment не реализован.
